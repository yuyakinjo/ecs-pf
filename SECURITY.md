# Security Policy

## Reporting a vulnerability / 脆弱性の報告

Please report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/yuyakinjo/ecs-pf/security/advisories/new).
Do not disclose vulnerability details in public issues or pull requests.

脆弱性を発見した場合は、上記リンクから非公開で報告してください。
公開 Issue や Pull Request には脆弱性の詳細を記載しないでください。

Include the affected version, reproduction steps, expected and actual behavior,
and potential impact. Remove AWS credentials, tokens, personal information,
and other sensitive data from examples and logs.

影響を受けるバージョン、再現手順、期待する動作と実際の動作、想定される影響を
記載してください。サンプルやログから AWS 認証情報、トークン、個人情報などを
削除してください。

Please coordinate public disclosure with the maintainer through the private
report so that remediation can be discussed before details are published.

詳細を公開する前に、非公開の報告内でメンテナーと修正・公開時期を相談してください。
